#  📝 Note App

A **Flutter Notes Application** with local database support using **SQLite**.  
Create, edit, and manage your daily notes with a smooth and clean user experience.


## ✨ Features

✅ Add Notes  
✅ Edit Existing Notes  
✅ Delete Notes  
✅ Local Storage with SQLite
